# Програми (полиця оновлень)

Публічна полиця готових файлів для пристроїв Пласту у Фінляндії. Тут лише зібрані програми й номер версії — **без коду, ключів і даних сайту**. Код лежить у приватних репозиторіях.

| Тека | Що це | Хто бере |
|---|---|---|
| `hy300-launcher/` | лаунчер проєктора HY300: `hy300-launcher.apk` + `version.json` (`code` — номер збірки, `date`) | сам лаунчер на проєкторі перевіряє кожні 2 хв і пропонує оновитись |

Файли кладе Claude скриптом `_vydaty/vydaty.sh` з репозиторію програми після зеленої збірки. Вручну нічого не вантажити.
